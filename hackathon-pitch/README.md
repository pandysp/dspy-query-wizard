# Hackathon Pitch Presentation

A Next.js web presentation for pitching automated prompt engineering solutions.

**Theme:** From Prompt Voodoo to Production-Ready AI

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the presentation.

## Build for Production

```bash
npm run build
npm start
```

## Deploy

Deploy easily with Vercel:

```bash
npx vercel
```

Or use the [Vercel Platform](https://vercel.com/new) - the easiest way to deploy Next.js apps.

## Features

- Responsive design
- Smooth scrolling navigation
- Dark theme with gradient backgrounds
- Full-screen sections for presentation mode
- Mobile-friendly layout

## Presentation Sections

1. **Hero** - Opening statement and value proposition
2. **Problem** - Challenges in AI production deployment
3. **Customer** - Target market and opportunities
4. **Demo** - User journey and solution demonstration

## Editing

Edit the content in `app/page.tsx`. The page auto-updates as you edit the file.
